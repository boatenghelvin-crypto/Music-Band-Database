# Music Band Database

CIS 344 Music Band Website Database Project

## Project Description
This project is a database system designed for a music band website. The database stores and organizes information about band members, albums, songs, venues, and events.

## Database Tables
- Band Member
- Album
- Song
- Venue
- Event
- Member Event

## Project Files
- `music_band_db.sql` - Database structure and tables
- `music_band_data_queries.sql` - Sample data and SQL queries
- `music_band_db.mwb` - MySQL Workbench model
- `Music_Band_Workbench_ER_Diagram.png` - MySQL Workbench ER diagram
- `IMG_2820.jpeg` - Hand-drawn Chen ER diagram
- `Final Report.pdf` - Final project report
